# Intelligent Ambulance Positioning System (IAPS)

A secure web application for optimal ambulance positioning using deep embedded clustering analysis.

## Features

- **Secure Login System**: Role-based authentication for operators, administrators, and analysts
- **Session Management**: Encrypted password storage and session timeout
- **Deep Clustering Visualization**: Interactive accident cluster analysis
- **Ambulance Positioning**: Model-driven location predictions
- **Data Upload**: Secure file upload for accident data
- **Responsive Design**: Works across all devices

## Usage

1. Open `index.html` in a web browser
2. Login with demo credentials
3. Access dashboard features based on your role
4. Upload accident data and view clustering analysis
5. Calculate optimal ambulance positions
